# 剧情卡生成提示词（严格时间轴版）

旧的「模板 A / 模板 B」已由两套**自包含**提示词替代：不需要再附 `剧情卡制作指南.md`，复制对应文件里的提示词块即可。

| 你的素材 | 用哪一份 |
| --- | --- |
| 一段剧情概要、设定、小说片段、口述点子 | [`严格时间轴-剧情概要提示词.md`](严格时间轴-剧情概要提示词.md) |
| SillyTavern 剧情卡（角色卡 JSON/PNG 文本、世界书、系统提示、first_mes） | [`严格时间轴-ST剧情卡提示词.md`](严格时间轴-ST剧情卡提示词.md) |
| 只转剧情/预设，**不产出角色卡**，房间里已有角色池 | [`plot-to-config-prompt.md`](plot-to-config-prompt.md)（保留原精简版） |
| 想查字段语义、限制、跨字段校验和完整示例 | [`剧情卡制作指南.md`](剧情卡制作指南.md)（说明书，不是提示词） |

## 两套新提示词都包含

- 完整字段表与长度限制；
- 严格时间轴硬规则：`regions` + `world.start_region` + `time_config.enabled=true`，不写 `schedule`；
- 地区图、门锁与钥匙替代路径、事件排期、耗时校准；
- 玩家人数 N（1–7）与「NPC 不得进入 characters」；
- 输出前自检清单。

## 第二套额外包含

- 叙事 / 插件二分：HTML、CSS、JS、EJS、`{{...}}`、`[InitVar]`、`<UpdateVariable>`、表单、按钮、状态栏、属性表等不进入 `opening`；
- 开场净化五步：提取叙事 → 删插件/UI → 设定转写 `scenario/guidance` → 通读检查 → 不足 200 字则省略 `opening`；
- 单人 → 多人：A/B/C 分类、B/C 绝不放进 `characters`、补足同席者不持有核心秘密。

## 生成之后

1. 把 AI 输出的 JSON 存成 `.json` 文件（建议 `有意义的文件名.anyworld.json`）。
2. 建房页点「导入配置」加载；导入是合并，`characters` 会清空重建。
3. 检查角色池至少有一个角色，并勾选自己要扮演的角色。
4. 常见报错定位见 `剧情卡制作指南.md` 第十四、十五部分。
